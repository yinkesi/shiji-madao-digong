# 实验史记 · 马刀地宫

> 据音克思《实验史记》改编 · 终卷。
> 毕业之后，校园沉入地下，化作九层地宫。——既毕业，无复有刀者；然地下九层，刀声未绝。

前作《实验史记·马刀行》是「开放校园箱庭 × 7×7 马刀战棋」。本作是其**完全玩法重构**：一虑存续，只余下探——**Roguelike 地宫爬塔**。九层地宫随机生成，走一步、世界走一步；斩各层镇守，胜一场、录一技，为《实验史记》收最后一卷。

## 快速开始

- **直接玩**：双击 `实验史记·马刀地宫.html`（单文件成品，零外部资源，file:// 可玩）。
- **开发模式**：双击 `index.html`，或 `python -m http.server` 后访问。
- **打包**：`python build.py` → 重出单文件成品。
- **测试**：
  - 引擎层：`for f in tests/test_*.mjs; do node $f; done`（6 套 Node 测试，96 项断言：生成连通性 / 回合引擎 / 九种特则 / 流程结算 / RNG / **平衡哨兵——机器人试玩一层通过率**）；
  - 全链路：`NODE_PATH=<全局 node_modules> node smoke.mjs`（Playwright 16 项：含 UI 通道全程打到终局结算，截图入 `testshots/`）；
  - 单文件复测：`node smoke.mjs "实验史记·马刀地宫.html"`。

## 玩法结构

| 层 | 内容 |
|---|---|
| 地宫层 | 九层随机生成（房间+走廊+战争迷雾），逐层主题化：跑道之下 → 异能之窟 → 三国刀廊 → 协会堂 → 合流渊 → 禁令厅 → 神算之间 → 崇国庭 → 终焉之庭 |
| 战斗层 | 回合制网格战（新引擎）：走/砍/技/物/待机；急击勿失（先手+2）、击破回血2、血祭翻倍、中毒/晕眩/缴械/护盾 |
| 特则层 | 每层一条地宫规则（难在机制不在数值）：情比金坚 / 党争 / 起义 / 鲍鱼之肆 / 锁门 / 验算 / 种树不绝 / 看台飞瓶 |
| 成长层 | 轮内：录技（首杀有名角色录其技）+ 刀卡遗物八种 + 木箱/商摊/灶间；轮外：文脉 → 修炼树八节点、点将名册（首斩镇守解锁八将）、难度五档 |
| 叙事层 | 史官记事以文言记之；镇守各有挑衅台词；前作主线九节化为九层沉入地底，终焉收卷 |

## 设计约定

- **零依赖**：原生 JS + Canvas 2D + WebAudio 程序合成，无任何外部资源与网络请求。
- **核心层不碰 DOM**：`rng/grid/data/gen/engine/meta/run` 在 Node 里经 `vm` 直测；表现层单独成层。
- **引擎可回放**：所有随机走 `G.r`（可播种、状态可序列化），同种子同宫、续局不换序列。
- **全局命名空间 `MDG`**：核心层以 `(typeof window !== "undefined" ? window : globalThis)` 双端挂载，经典 `<script>` 按序加载。
- **存档**：`localStorage['shiji_digong_v1']`（文脉/修炼/名册/图鉴/设置）+ `shiji_digong_run_v1`（本轮逐动自动存）。系统面板可导出/导入/焚稿重开。
